# RIVER

친구끼리 초대 링크로 모여 가상 칩으로 즐기는 2~9인 텍사스 홀덤입니다. 외부 런타임 라이브러리 없이 브라우저 화면과 Cloudflare Worker, SQLite 기반 Durable Object로 구성했습니다.

배포 주소: [RIVER](https://river-friends-holdem.hanroona8844.workers.dev)

2026-10-23 화면과 기록 개선을 배포했습니다. 기존 회원 8명과 수동 게임 기록 1개를 보존했고, 운영 화면에서 별도 기록의 생성과 같은 ID 수정, 새로고침 후 재열기, 랭킹 반영을 확인했습니다. 검증에 사용한 기록과 방은 정리했습니다. [이번 배포와 데이터 보존 검증](docs/deployment-2026-10-23.md)을 참고하세요.

기존 게임 엔진과 Cloudflare Worker 및 Durable Object 구조를 유지했습니다. 화면과 기록 변경 범위는 [개선 내용](docs/improvements-2026-10-23.md)에 정리했습니다. 2026-10-12 배포와 실시간 게임 검증은 [이전 배포 기록](docs/deployment.md)에 남아 있습니다.

## 실행

Node.js 22 이상이 필요합니다.

```sh
npm ci
npm run dev
```

http://localhost:8787 에서 기본 회원 이름을 선택하고 테이블을 엽니다. 새 회원은 기수와 이름을 입력해 등록하고 입장하거나, `등록만 하기`로 가입한 뒤 나중에 참여할 수 있습니다. 초대 링크를 공유한 뒤 2명 이상 준비하면 방장이 시작할 수 있습니다. 로컬 주소는 같은 컴퓨터에서만 접근할 수 있습니다. 친구들과 인터넷에서 플레이하려면 배포가 필요합니다.

## 포함된 기능

- 2~9인 비공개 테이블, 64비트 무작위 초대 코드, 초대 링크 복사 또는 기기 공유 메뉴
- 반응형 모바일 화면과 데스크톱 화면, 앱 형태로 열기 위한 웹 앱 매니페스트
- 기본 회원 이름 선택과 기수 및 이름 가입 명단, 등록만 하기, 회원별 기록 구분
- 홈의 멤버 관리에서 기본/등록 멤버 삭제, 삭제 확인과 취소, 과거 기록 및 랭킹 보존
- 익명 브라우저 세션, 자동 재접속, 중복 입장 방지, 오프라인 방장의 역할 인계
- 노리밋 홀덤, 블라인드 150/300, 시작 및 리바인 칩 30,000, 폴드, 체크, 콜, 레이즈, 올인
- 서버의 암호학적 난수 셔플, 족보와 킥커 비교, 사이드 팟, 초과 베팅 반환, 동점과 홀수 칩 분배
- 최소 레이즈, 짧은 올인과 누적 올인에 따른 재레이즈 권한 검증
- 행동 제한 45초, 시간 초과 시 체크 가능하면 체크하고 그 외에는 폴드
- 방별 누적 칩 순이익, 핸드 수, 승수와 최근 30핸드 결과 저장
- 홈 랭킹: 주간 우승과 누적 리바인 정렬, 지난 게임 날짜와 참가자별 승리 및 리바인 횟수 입력, 같은 기록 다시 열어 수정
- 리바인 횟수별 날짜와 시각 입력, 한국 시간 기준 표시, 모르는 시각은 `미기록`으로 구분
- 테이블 주간 칩 장부: 30,000칩 기준의 세션별 리바인과 종료 칩 기록, 주간 우승과 누적 순이익 집계, 기록 수정과 삭제 및 JSON 백업
- 최근 방문한 5개 방 바로가기, 카드 예시가 있는 홀덤 족보와 프리플랍 시작패 및 게임 방법 가이드

홈 랭킹은 회원별 지난 게임 기록과 테이블 주간 칩 장부를 합산합니다. 주간 우승은 한국 시간으로 월요일부터 일요일까지의 기록을, 누적 리바인은 모든 기간의 기록을 집계합니다. 홈에서 `지난 게임 기록`을 열어 참가자 2~9명과 승리 및 리바인 횟수를 입력합니다. 리바인 시각은 비워둘 수 있으며, 저장한 기록의 `수정`으로 날짜와 횟수를 바꾸면 같은 ID의 기록이 갱신되고 랭킹도 다시 계산됩니다.

멤버를 삭제하려면 홈의 `멤버 관리`에서 이름 옆 `삭제`를 누른 뒤 `삭제 확인`을 누릅니다. 삭제한 멤버는 새 테이블과 새 기록의 선택 명단에서 빠집니다. 과거 기록과 랭킹은 `삭제된 멤버` 표시로 남고, 이미 참여한 기록은 계속 수정할 수 있습니다. 등록회원은 같은 기수와 이름으로 다시 가입하면 기존 회원 키와 기록을 이어갑니다. 삭제는 명단 제외 방식이며 개인정보와 과거 기록의 완전 삭제 기능은 아닙니다.

테이블 안의 리더보드는 해당 방의 핸드 전적입니다. 정산된 순이익, 승수 순으로 정렬하며 사이드 팟이나 동점 팟을 받아도 승리로 셉니다. 칩 충전은 순이익에 더하지 않습니다. 외부 선수 랭킹 수집과 현금 결제, 환전은 없습니다.

주간 칩 장부는 홀덤 핸드 랭킹과 별도로 운영됩니다. 게임이 끝난 뒤 방장이 참가자별 리바인 횟수와 종료 칩을 세션 기록으로 저장하면, 시작 칩과 리바인 칩을 뺀 순이익 및 월요일부터 일요일까지의 우승 횟수를 집계합니다. 날짜별 기록은 수정하거나 삭제할 수 있고 JSON으로 내려받을 수 있습니다. 새 세션 기록의 참가자는 현재 테이블 참가자 중에서 고릅니다. 같은 게임을 홈과 테이블 장부 양쪽에 새로 입력하면 각각 별도 기록으로 합산되므로 한 곳에 기록합니다. 새 테이블은 시작 칩 30,000개, 블라인드 150/300으로 시작합니다. 기존에 저장된 테이블은 칩 기록과 블라인드를 15배로 환산해 기존 스택 깊이를 유지합니다. 이 환산 로직은 이번 개선에서 변경하지 않았습니다.

같은 브라우저의 HttpOnly 쿠키로 재입장합니다. 기기 간 계정 연동은 없으며, 다른 브라우저나 기기에서는 별도 참가자로 입장합니다. 쿠키를 지우면 기존 참가자 신원을 복구할 수 없습니다. 친구에게는 방 링크만 전달되고 개인 세션 쿠키는 전달되지 않습니다.

## 검증

```sh
npm test
npm run check
npm run deploy:check
```

별도 터미널에 로컬 서버를 켠 상태에서 실시간 연결을 검사합니다.

```sh
node test/integration.mjs
```

`test/poker.test.js`는 최대 9인과 시작 칩 30,000, 홀덤 경계 조건, 무작위 500핸드의 칩 보존을 검사합니다. `test/records.test.js`는 격리된 Miniflare의 SQLite Durable Object에 기존 형식 데이터를 넣어 조회, 같은 ID 수정, 동명이인 분리, 동시 저장, 재시작 후 복구를 검사합니다. `test/integration.mjs`는 두 독립 세션의 API와 WebSocket, 개인 패 비공개, 오래된 명령 거부, 정산, 재접속, 방장 이전을 검사합니다.

2026-10-23 테스트 24개와 로컬 WebSocket 통합 검증이 통과했습니다. 로컬 홈과 9인 테이블은 320px부터 1440px까지 확인했고, 가로 화면을 포함해 넘침과 좌석 겹침이 없었습니다. 기록 저장과 수정 후 새로고침, 등록만 한 뒤 입장, 가이드 전환을 확인했습니다. 배포 후에는 운영 화면의 기록 수정과 랭킹 반영, 기존 회원 및 기록의 저장 원문 보존까지 확인했습니다. [이번 개선 검증](docs/improvements-2026-10-23.md)과 [배포 검증](docs/deployment-2026-10-23.md)에 범위를 기록했습니다. 2026-10-12의 Chrome 및 Safari 검수는 [이전 기기별 검수](docs/device-qa.md)에 별도로 남아 있습니다. 실제 iOS, Android, Windows 기기에서는 별도 검증이 필요합니다.

## Cloudflare 배포

1. Cloudflare 계정에서 **Workers Free** 플랜인지 확인합니다. 기존 유료 계정에 배포하면 해당 계정의 과금 정책이 적용됩니다.
2. 로컬에서 로그인합니다. 승인 화면은 계정 소유자가 직접 확인합니다.
3. 아래 명령으로 기본 `workers.dev` 주소에 배포합니다. 별도 유료 도메인은 필요하지 않습니다.

```sh
npx wrangler login --scopes account:read user:read workers_scripts:write
npm run deploy
```

계정이 여럿이면 배포 대상 계정을 명시해야 합니다. 방 데이터는 해당 계정의 Durable Object에 저장됩니다. 코드의 `PokerRoom` 클래스명과 마이그레이션 이력은 기존 데이터를 유지하려면 보존해야 합니다.

배포 명령 실행 전에는 인터넷 공개 주소가 만들어지지 않습니다. 로컬 테스트 데이터는 원격 배포로 업로드되지 않습니다.

## 비용 조건

2026-10-12 확인한 [Workers 공식 요금](https://developers.cloudflare.com/workers/platform/pricing/)과 [Durable Objects 공식 요금](https://developers.cloudflare.com/durable-objects/platform/pricing/)을 기준으로 설계했습니다.

- Workers Free: 동적 요청 하루 100,000회. 정적 자산은 Workers 정적 자산 제공을 이용합니다.
- Durable Objects Free: 하루 100,000요청과 13,000GB-s 실행 시간, SQLite 읽기 500만 행과 쓰기 10만 행, 총 저장 공간 5GB.
- Free 플랜은 한도 초과 시 요청이 실패합니다. 무료로 무제한 서비스를 제공하는 구성은 아닙니다.
- WebSocket Hibernation을 사용해 연결 대기 중 실행 시간 소모를 줄입니다. 앱의 핑은 런타임 자동 응답을 사용합니다.
- 유료 플랜 전환, 유료 도메인, R2, 외부 DB, 유료 인증, 분석 SDK는 요구하지 않습니다.

공개 배포 후 무료 사용량은 Cloudflare 대시보드에서 확인하세요. 모르는 사람에게 링크를 널리 공개하는 서비스로 확장하려면 방 생성 남용 방지, 계정 기반 신원, 데이터 보존 정책을 별도로 설계해야 합니다.

## 파일 구성

- `src/poker.js`: 네트워크와 독립적인 홀덤 엔진
- `src/worker.js`: 세션, 초대 입장, WebSocket, 서버 상태와 기록 저장
- `public/fonts/`: 직접 제공하는 글꼴. 보안 정책상 외부 글꼴 서버를 쓰지 않습니다. 본문은 Pretendard 1.3.9(SIL Open Font License, `Pretendard-LICENSE.txt` 포함), 제목은 G마켓 산스 Bold(G마켓 무료 배포 글꼴)입니다.
- `public/`: 브라우저 화면, 디자인, 매니페스트와 보안 헤더
- `test/`: 규칙 및 서버 통합 검증
- `docs/improvements-2026-10-23.md`: 홈과 기록 개선 범위, 기존 저장값 보존 검증
- `docs/deployment-2026-10-23.md`: 운영 배포, 기록 수정 검증과 테스트 데이터 정리
- `docs/benchmark.md`: BGA에서 실제 확인한 흐름과 구현 범위
- `docs/screenshots/`: 브라우저 검수와 배포 화면
