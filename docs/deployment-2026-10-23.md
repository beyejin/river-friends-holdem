# RIVER 개선 배포와 데이터 보존 검증

- 배포일: 2026-10-23
- 운영 주소: [RIVER](https://river-friends-holdem.hanroona8844.workers.dev)
- 최종 배포 버전: `ebe25b5a-aead-4a05-9620-16409f10e30c`

기존 Worker `river-friends-holdem`, 바인딩 `ROOMS`, Durable Object 클래스 `PokerRoom`, 마이그레이션 `v1`, 네임스페이스 `9d97cd87926241e4a0662e3541e06d78`을 유지한 채 화면과 기록 개선을 배포했습니다. 게임 엔진과 저장 키를 바꾸거나 데이터를 일괄 변환하지 않았습니다.

## 기존 데이터 보존

배포 전 회원 8명과 2026-10-21 수동 게임 기록 1개를 기준으로 비교했습니다. 별도 검증 기록을 정리한 뒤 회원 및 기록의 저장 원문을 깊은 비교로 대조해 모두 일치하는 것을 확인했습니다. 기존 랭킹의 핵심 점수도 동일했습니다. 랭킹 응답에 회원 구분용 `key`와 `cohort`가 추가되는 것은 의도한 변경이며, 기존 기록 원문을 다시 쓰는 변경은 아닙니다.

## 배포 후 기록 수정

운영 화면에서 별도 검증 기록 1개를 만들고 다시 열어 게임 날짜, 승리 횟수, 리바인 횟수와 시각을 수정했습니다. 모르는 시각은 비워 두었습니다.

새로고침 후 기록을 다시 열어 수정값과 `미기록` 표시가 유지되는 것을 확인했습니다. 수정은 같은 ID에 반영되어 새 기록이 중복 추가되지 않았습니다. 검증 기록을 이전 주로 옮긴 뒤 해당 기록의 이번 주 우승 집계는 0으로, 누적 리바인은 3으로 반영됐습니다. 기존 기록은 바뀌지 않았습니다.

화면: [배포 홈](screenshots/deployed-home.png), [모바일 족보](screenshots/deployed-hands-mobile.png), [모바일 프리플랍](screenshots/deployed-preflop-mobile.png).

최종 배포에서도 320px와 390px 화면의 가로 넘침이 없고, 기존 기록의 수정 입력값과 가이드 탭이 정상 표시됐습니다. 브라우저 오류는 없었습니다. 배포된 정적 파일 7개는 로컬 파일과 SHA-256이 모두 같았고, 응답 헤더 5개도 설정과 일치했습니다.

## 검증 데이터 정리

- 운영: 이번 검증 기록 1개와 과거 자동 검증 방 3개를 삭제했습니다. 정리 후 기존 회원과 기록의 원문 및 랭킹 핵심 점수를 다시 비교했습니다.
- 로컬: 검증 서버 8787과 8791을 정상 종료하고, 삭제 직전 목록에 새 데이터가 없는지 확인했습니다. 테스트방 15개, 테스트 회원 1명, 수동 기록 1개와 방 장부 1개가 들어 있던 `/tmp/river-improvement-state`와 `.wrangler/state`를 삭제했습니다. 두 경로의 부재와 포트 종료를 재확인했습니다.
- 로컬 검증 브라우저의 회원 선택값, 방문 기록과 세션 쿠키를 제거했습니다. 임시 검증 기록 파일, 방 스냅샷, 관리 토큰과 작업 스크립트도 삭제했습니다.
- 테스트 코드, fixture 소스와 `.wrangler/tmp`는 유지했습니다. 로컬 테스트 데이터는 배포 과정에서 운영으로 복사되지 않았습니다.

운영 데이터 대조와 정리에는 강한 인증을 적용한 임시 관리 wrapper를 사용했습니다. 배포 전 관련 경계 검증 19개를 통과했으며, 최종 버전에서는 wrapper를 제거하고 원래 `src/worker.js`를 배포했습니다. 임시 관리 경로를 제품 기능으로 남기지 않았습니다.

최종 버전의 100% 적용과 기존 저장소 연결을 다시 확인했습니다. 이전 관리 토큰으로 접근해도 해당 기능은 실행되지 않으며, 일반 세션 확인 후에는 404를 반환합니다. Cloudflare에서 내려받은 최종 Worker 원본에도 임시 관리 코드가 없는 것을 확인했습니다.

로컬 테스트 24개, WebSocket 통합 검증, 화면과 데이터 변경 범위는 [개선 검증](improvements-2026-10-23.md)을 참고하세요. 실제 iOS, Android 및 Windows 기기의 검수는 이번 범위에 포함되지 않습니다.
