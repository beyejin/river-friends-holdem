# BGA 홀덤 벤치마킹

2026-10-12, 사용자가 제공한 [BGA 테이블 #929820717](https://boardgamearena.com/tableview?table=929820717)을 로그인된 브라우저에서 읽기 전용으로 확인했습니다. 게임에 참여하거나 행동을 입력하지 않았습니다.

| --- | --- |

| 프리플롭부터 리버까지 단계별 진행 | 단계 이름, 팟, 공용 카드, 행동 가능 버튼 표시 |

| 플레이어 프로필과 전적 표시 | 우리 방에서 완료한 핸드의 순이익과 승수 기록 |

화면의 흐름과 정보 배치를 참고했으며 BGA의 코드, 카드 이미지, 로고와 플레이어 기록은 앱에 복사하지 않았습니다. 카드와 테이블은 CSS와 기본 글꼴로 직접 표현합니다.

## 선택한 범위

친구용 가상 칩 게임을 우선합니다. 블라인드는 10/20 고정, 참가자는 2~6명이며 핸드 사이에 참여와 퇴장이 가능합니다. 핸드 도중 연결이 끊기면 자리는 유지하고 시간 초과 규칙으로 진행합니다. 다음 핸드는 준비한 사람만 참여합니다.

초대 링크가 접근 권한입니다. 링크를 가진 사람은 빈자리에 들어올 수 있으므로 별도 초대 수락, 친구 목록, 방 암호 기능은 포함하지 않습니다. 신규 입장은 핸드가 끝난 뒤 가능합니다. 방별 랭킹은 유지하지만 서로 다른 방을 합친 전역 랭킹과 기기 간 계정 연동은 포함하지 않습니다.

## 구조

브라우저는 행동 의도만 보냅니다. Cloudflare Worker가 브라우저의 HttpOnly 쿠키를 확인하고, 각 방을 담당하는 Durable Object가 덱, 순서, 베팅과 정산을 결정합니다. 본인 패와 공개해도 되는 정보만 참가자별로 다르게 전송합니다. 방 상태와 기록은 SQLite 기반 저장소에 함께 저장하며 명령에는 리비전을 붙여 중복 클릭이나 이전 상태에서 온 행동을 거부합니다.

Cloudflare의 [WebSocket Hibernation 문서](https://developers.cloudflare.com/durable-objects/examples/websocket-hibernation-server/)를 참고해, 항상 실행되는 외부 서버 없이 실시간 연결과 대기 상태를 처리합니다.
